## Technical Implementation

### Tools Needed

| Tool | Purpose |
|------|---------|
| **Email Platform** | Mailchimp, SendGrid, or ActiveCampaign |
| **Segmentation** | Intercom export → segment by activity |
| **Tracking** | UTM parameters for each email |
| **Automation** | Drip sequence with stop triggers |

### Stop Triggers

| Trigger | Action |
|---------|--------|
| Clicked "Start Trial" | Remove from sequence |
| Booked demo | Remove from sequence |
| Replied to email | Manual follow-up |
| Unsubscribed | Remove from all |

### UTM Parameters

```

&utm_medium=reengagement
&utm_campaign=titlegenie_jan2026
&utm_content=email1_day0
```
