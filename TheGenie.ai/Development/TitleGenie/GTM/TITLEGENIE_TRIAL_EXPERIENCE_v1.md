## The Goal

**Convert prospects to paying customers by letting them experience value BEFORE committing to $250/month.**

---

## Trial Structure Options

### Option A: Time-Limited Trial (Recommended)

| Component | Details |
|-----------|---------|
| **Duration** | 7 days |
| **Access Level** | Full TitleGenie access |
| **Limitations** | 0 Listing Commands (no gifting during trial) |
| **Agent Invitations** | Up to 5 during trial |
| **Payment Required** | Credit card on file (not charged until trial ends) |
| **Conversion Trigger** | Trial expires → Auto-charge unless cancelled |

### Option B: Feature-Limited Trial

| Component | Details |
|-----------|---------|
| **Duration** | 14 days |
| **Access Level** | Limited features |
| **Limitations** | View-only Farm Analyzer, no Agent Scorecard, no Listing Commands |
| **Agent Invitations** | 0 during trial |
| **Payment Required** | No card required |
| **Conversion Trigger** | Must upgrade to access full features |

### Option C: Guided Demo + Trial Hybrid

| Component | Details |
|-----------|---------|
| **Duration** | 7 days (after 15-min demo call) |
| **Access Level** | Full access |
| **Limitations** | Must complete demo to unlock trial |
| **Agent Invitations** | Up to 5 during trial |
| **Payment Required** | Card on file after demo |
| **Conversion Trigger** | Trial expires → Auto-charge |

---

## Recommended Approach: Option A + Demo Offer

**Best of both worlds:**

1. **Self-service trial** available for those who want to explore immediately
2. **Demo offer** prominently displayed for those who want guidance
3. **Card on file** required to reduce tire-kickers
4. **7 days** is enough to experience value without dragging out decision

## Technical Requirements

### Trial Account Flags

```sql
-- New fields for trial tracking
UserTrialStartDate DATETIME
UserTrialEndDate DATETIME
UserTrialStatus VARCHAR(20) -- 'Active', 'Converted', 'Expired', 'Cancelled'
UserAgentInviteLimit INT DEFAULT 5 -- During trial
UserListingCommandsAllowed INT DEFAULT 0 -- During trial
```

### Trial Expiration Logic

```
DAILY JOB:
1. Find all users where TrialStatus = 'Active' AND TrialEndDate < TODAY
2. For each:
   a. Attempt charge on card
   b. If success: 
      - Set TrialStatus = 'Converted'
      - Set AgentInviteLimit = 50
      - Set ListingCommandsAllowed = 4
      - Send welcome email
   c. If fail:
      - Set TrialStatus = 'Expired'
      - Revoke dashboard access
      - Send exit email
```
