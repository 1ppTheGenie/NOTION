## 🎯 WHAT IS THIS?

This is a **file-based agent collaboration system** for coordinating multiple specialized agents (AI assistants or human developers) working on the PLS Pre-Listing Command project.

**Note:** Cursor does not have built-in agent configuration, so we use a file-based system for coordination.

## 🔄 HOW IT WORKS

### Agent Assignment
- **Option 1:** Human developers assigned to roles
- **Option 2:** Separate AI assistant sessions for each role
- **Option 3:** Hybrid approach (humans + AI)

### Coordination
- **Status Files:** Each agent maintains their own status file
- **Master Dashboard:** `AGENT_STATUS_ALL_v1.md` shows all agents
- **Blockers:** Document blockers in `BLOCKERS_v1.md`
- **Handoffs:** Create handoff entries in `HANDOFFS_v1.md`

### Communication
- **File-Based:** All communication through markdown files
- **Templates:** Use templates for blockers and handoffs
- **Daily Updates:** Update status files daily

## 🚨 CRITICAL RULES
