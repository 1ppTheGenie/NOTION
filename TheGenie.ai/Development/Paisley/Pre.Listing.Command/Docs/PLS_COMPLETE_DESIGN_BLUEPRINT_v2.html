Phase 2: Listing Type & Details
2️⃣ Select Status → 3️⃣ Property Details → Valid?
↳ NO → ❌ Highlight invalid fields
↳ YES → Continue to Phase 3
📝 NOTES: Phase 2
Phase 3: Photos & Description
4️⃣ Upload Photos → ☁️ S3 Upload → ≥1 Photo?
↳ NO → ❌ "At least 1 photo required"
↳ YES → 5️⃣ Description → Use AI?
↳ YES → 🤖 Paisley AI | NO → ✍️ Manual Entry
📝 NOTES: Phase 3
Phase 4: Agent & Area Selection
6️⃣ Select Agent → User Role?
↳ Agent → Load Own Profile
↳ Title Rep → Query Partners
↳ Admin → Search All Agents
→ 7️⃣ Select Area → Continue
📝 NOTES: Phase 4
Phase 5: Review, Save & Publish
8️⃣ Review → Publish → 🔢 PLS# → INSERT Listing
→ INSERT Photos → INSERT Ownership → Success?
↳ ERROR → ❌ Rollback + Show Error
↳ SUCCESS → 🎨 GenieCloud Render → 9️⃣ Success! → ✅ END
