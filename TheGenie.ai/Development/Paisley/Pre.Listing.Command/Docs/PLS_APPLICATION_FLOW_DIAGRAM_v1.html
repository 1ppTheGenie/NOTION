❓ "What If" Decision Matrix

Scenario What Happens User Action
Address not found in geocoding Error shown, stays on Screen 1 Re-enter address or use manual coordinates
No Attom data for property Warning shown, proceed with empty form Enter all fields manually
Photo upload fails Red X on failed photo, retry button Click retry or remove and re-upload
No photos uploaded Cannot proceed, error message Must upload at least 1 photo
Paisley AI times out Show timeout message, enable manual entry Type description manually or retry
Title Rep has no partner agents Show empty state with "Invite Agent" button Invite agent first, or use Admin flow
Database insert fails Transaction rolled back, error shown Retry, data preserved on form
GenieCloud render fails Listing created, but assets pending Assets will retry automatically via queue
User refreshes mid-wizard Session state preserved (localStorage backup) Continue from where they left off
User closes browser mid-wizard Draft saved if > Screen 3 Resume from drafts on next login
