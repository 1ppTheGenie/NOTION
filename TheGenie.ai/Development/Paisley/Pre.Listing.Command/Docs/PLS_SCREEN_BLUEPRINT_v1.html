📍 Property Address Entry

/pls/create

Create Private Listing

Google Places autocomplete enabled

📥 Input Fields
  • 📍 Address: Text with Google Places autocomplete
  • 🏙️ City: Auto-filled from autocomplete
  • 🗺️ State: Dropdown, auto-selected
  • 📬 ZIP: Auto-filled, 5 digits
✅ Validation Rules
  • • Address must be parseable by Google
  • • Must have street number
  • • Must be US address
  • • ZIP must be 5 digits
❌ Error States
  • Address not found: "We couldn't find this address. Please check the spelling or enter manually."
  • Missing street number: "Please include the street number."
  • Invalid ZIP: "Please enter a valid 5-digit ZIP code."
🗄️ API Calls
Service Google Places Autocomplete
Returns Formatted address, lat/lng, components

⚠️ What If No Data Found?

Show warning: "No property records found. You'll need to enter all details manually on the next screen."

User can still proceed - this is NOT a blocker.

🏠 Property Details

/pls/create/details

Property Details

Pre-filled from Attom
📥 Required Fields
  • 💰 Price: Integer > 0, < 999,999,999
  • 🛏️ Bedrooms: Integer 0-99
  • 🛁 Bathrooms: Integer 0-99
  • 📐 Square Feet: Integer > 0
  • 📅 Year Built: 1800 to current+1
📥 Optional Fields
  • 🌳 Lot Size (sq ft)
  • 🚗 Garage Spaces
  • 🏫 School District
  • 🏘️ Neighborhood Name
🗄️ Database Mapping
Target Table MlsListing.dbo.Listing
Price → PriceLow
Bedrooms → Bedrooms
Bathrooms → BathroomsFull
Sqft → SqFtTotal
❌ Validation Errors
  • Price = 0: "Please enter a valid price"
  • Year > 2026: "Year built cannot be in the future"
  • Missing required: Highlight field with red border

✍️ Property Description

/pls/create/description

Property Description

🤖
Paisley AI
Generate a professional description
🤖 Paisley AI Integration
  • • Uses ChatStartTypeId=3 (Pre-Listing Focused)
  • • Inputs: Address, beds, baths, sqft, year, neighborhood
  • • Sources data from Assessor, NOT MLS
  • • User can edit generated text
✍️ Manual Entry Option

User can skip AI and type/paste their own description. Minimum 50 characters recommended (soft validation).

❌ Error States
  • AI timeout: "Paisley is taking a while. You can type manually or retry."
  • Empty description: "Please add a property description"
🗄️ Database Mapping
Field MlsListing.dbo.Listing.Remarks
Type VARCHAR(MAX)
